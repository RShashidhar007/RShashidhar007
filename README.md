### 1. [CodeForge AI — Recruitment & Code Intelligence Platform](https://github.com/RShashidhar007/CodeForge-AI)

A recruitment platform concept that combines candidate/recruiter workflows with AI-assisted code intelligence.

**What it aims to solve**
- Organize candidate and recruiter experiences in one platform.
- Provide code explanation, bug analysis, improvement suggestions, and test-generation workflows.
- Support future repository indexing and context-aware code search.

**Implemented foundation**
- Candidate and recruiter registration/login with JWT authentication and BCrypt password hashing.
- Candidate/recruiter profile management and role-protected access.
- Admin dashboard and user-management APIs.
- Java Spring Boot backend with Spring Data JPA, Microsoft SQL Server, and Redis.
- React + TypeScript frontend, with Docker Compose for local services.

**Development status:** The core recruitment foundation is implemented. AI endpoints currently use mock responses; repository indexing, semantic search, and the multi-agent execution workflow remain under development.

**Tech stack:** Java 17+, Spring Boot, Spring Security, JWT, Spring Data JPA, SQL Server, Redis, React, TypeScript, Vite, Docker.

### 2. [AI-Powered Smart Campus Analytics & Early Risk Detection](https://github.com/RShashidhar007/AI-Powered-Smart-Campus-Analytics-Early-Risk-Detection-System)

An academic analytics platform designed to help faculty identify students who may need additional academic support using attendance, marks, assignments, and study patterns.

**Key features**
- Separate faculty/admin and student experiences.
- Student risk classification to highlight learners who may need support.
- Interactive dashboards and charts for attendance, grades, risk distribution, and academic trends.
- Prediction tools for marks and grades, plus feature-importance insights.
- Student-level recommendations and year-over-year comparisons.
- CSV, Excel, PDF, and Word data ingestion, with Excel/PDF report exports.
- Multilingual interface supporting English, Hindi, and Kannada.
- Contextual AI assistant integration through a Groq-compatible LLM API.

**Tech stack:** Python, Streamlit, SQLite, Pandas, NumPy, Scikit-learn, Plotly, Groq/OpenAI-compatible APIs, OpenPyXL, ReportLab.

**Project focus:** Turning academic data into understandable dashboards and early-warning signals that can support better-informed faculty decisions.
